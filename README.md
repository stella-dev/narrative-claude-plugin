# Narrative の Claude Code プラグイン

[Narrative](https://makenarrative.com) と Claude Code をつなぎます。Claude Code に 1 行ずつ貼ってください。

```
/plugin marketplace add stella-dev/narrative-claude-plugin
/plugin install narrative@narrative
```

入ったら「Narrative でテンプレートの作成を始めて」と打ちます。初めてのときは、AI が出す URL をブラウザで開いて「許可する」を押してください。開き直しは要りません。
